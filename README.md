# Web Development Bootcamp

This repository contains my work while going through **The Complete Web Development Bootcamp by Dr. Angela Yu**.

I'm using the course to build a stronger foundation in web development, with a particular focus on understanding how the different parts of a web application fit together.

## What I'm Learning

* HTML & CSS
* JavaScript
* DOM manipulation
* Bootstrap
* jQuery
* Node.js
* Express.js
* REST APIs
* Databases
* Authentication
* React
* Git & GitHub

## Approach

Rather than keeping this as a collection of copied course exercises, I'm using it to practice the concepts and experiment with them independently.

I'll be adding:

* Course exercises
* Small experiments
* Notes where useful
* Projects and applications built along the way

## Connecting It With Backend Development

I already have some experience working with **Java, Spring Boot, REST APIs, and PostgreSQL**, so one of my goals is to use what I learn here to better understand the frontend side of the client-server architecture.

The longer-term goal is to build applications where I can work across both sides:

```text
Frontend
React / JavaScript
       │
       │ HTTP / JSON
       ▼
Backend
Spring Boot / REST API
       │
       ▼
Database
PostgreSQL
```
